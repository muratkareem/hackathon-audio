# 🎙️ Steppe Hub: AI Meeting Intelligence

**Автономный ИИ-протоколист для бизнеса** — это локальное приложение для полной обработки записей рабочих встреч. Проект транскрибирует аудио, распознает голоса участников, составляет структурированные протоколы и рисует ментальные карты.

Решение работает **на 100% локально** (offline-first), обеспечивая абсолютную конфиденциальность корпоративных данных.

## ✨ Ключевые возможности

- 🗣️ **Интеллектуальная диаризация (Pyannote):** Автоматическое распознавание спикеров (кто и когда говорил).
- ⚡ **Сверхбыстрая транскрибация (Faster-Whisper):** Точный перевод голоса в текст с использованием модели `large-v3-turbo` с поддержкой Apple Silicon.
- 📋 **Структурированный ИИ-протокол (Ollama):** Генерация подробного Markdown-протокола с разделами: *Краткая выжимка*, *Принятые решения* и строгая *Таблица поручений (Action Items)*.
- 🎨 **Визуализация встреч (Mermaid + Rough.js):** Автоматическая генерация блок-схем и ментальных карт в стиле Excalidraw на основе обсуждений, с возможностью выгрузки в PNG/SVG.
- 💬 **Умный RAG-чат (Smart Q&A):** Система в фоновом режиме заранее генерирует релевантные вопросы по встрече. При клике ИИ мгновенно дает на них ответы.
- 📥 **Экспорт в 1 клик:** Скачивание протоколов в форматах PDF, JSON и CSV для удобной интеграции с корпоративными системами.

## 🛠 Технологический стек

- **Backend:** Python 3, FastAPI, Uvicorn, Pydub.
- **AI Models:** Pyannote Audio (Diarization), Faster-Whisper (ASR), Ollama LLaMA 3.1 8B (LLM).
- **Frontend:** Vanilla HTML/JS/CSS, Mermaid.js (v11), Marked.js, html2pdf.

## 🚀 Запуск проекта

### 1. Требования
- Python 3.10+
- [Ollama](https://ollama.com/) с загруженной моделью LLaMA 3.1 (`ollama run llama3.1`).
- Установленный `ffmpeg` (например, через `brew install ffmpeg` на macOS).

### 2. Настройка окружения
1. Склонируйте репозиторий.
2. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```
3. Откройте `.env` и вставьте ваш HuggingFace токен (`HF_TOKEN`) для доступа к модели Pyannote.

### 3. Запуск сервера
В проекте предусмотрен удобный bash-скрипт, который автоматически поднимет виртуальное окружение, установит все зависимости и запустит API:

```bash
chmod +x run_api.sh
./run_api.sh
```

Сервер будет доступен по адресу: **http://localhost:8000**
